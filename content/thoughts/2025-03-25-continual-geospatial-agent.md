I have developed a very useful Python [package](https://github.com/gladcolor/StreetView) to operate Google Street View images, but maintaining it is painful, because I have released more and more packages and research code. Maintenance is like "interest", and it keeps growing.

So I envision a continual agent, specialized in a relatively simple and specific task, such as maintaining a code repository or crawling data. It would be able to run and learn all the time, following the given "meta-instruction" forever. For example, it could keep adding functions to my street view image package, testing the functions, receiving pull requests, and creating documentation. That would be its only task.

I may have a research idea to prototype such an agent! I think it is amazing.
